About This Project

Simple POS is a minimal, black-and-white point-of-sale demo built with a Node.js/Express backend, a MongoDB Atlas database, and a plain HTML/CSS/JavaScript frontend — deployed as three independent services (Vercel for the frontend, Render for the API, Atlas for the database) to demonstrate a real-world, split-architecture web deployment.
